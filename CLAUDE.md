# CLAUDE.md

## Overview

`asterisk.cr` is a Crystal-lang all-in-one Asterisk PBX library - ARI, AMI, and all types of AGI - by Andrius / the ctiapps org (github.com/ctiapps/asterisk). Examples and demos live in the sibling `alice_calls` repo. Last commit 2019-10-26.

## Stack

Crystal (`shard.yml`, `src/`), Docker (`Dockerfile-13`, `Dockerfile-16`). Test: `crystal spec`.
